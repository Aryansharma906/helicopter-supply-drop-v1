# 🚁 Helicopter Supply Drop Simulation (Version 1)

A 2D physics simulation of a military supply drop built using **Matter.js** body engine and **p5.js** canvas rendering.

![Matter.js](https://img.shields.io/badge/Matter.js-black?style=for-the-badge)
![p5.js](https://img.shields.io/badge/p5.js-ED225D?style=for-the-badge&logo=p5dotjs&logoColor=white)

## 🎯 Features
- 🚁 **Helicopter Transport**: Renders a stationary/hovering helicopter entity.
- 🪂 **Physics Release**: Key trigger detaches the cargo box from static constraints.
